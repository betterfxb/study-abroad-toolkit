## 坑与排障

- **8080 上是 10-12 旧网关 pid16168**：新端点 404，杀掉重建 →「联调前确认端口进程是本轮构建」再应验。
- **PS5.1 curl JSON 内联 `-d` 会被搅坏**：改 `--data-binary @file`（UTF-8 无 BOM 写入），响应用 `[IO.File]::ReadAllText`。

- **会话默认 `node` 是 nvm v20.5.0**：`node:sqlite`/类型擦除/`--experimental-sqlite` 必须用受管 `binaries\node\versions\22.22.2-3\node.exe`；`npm test` 走 PATH node 会失败。已记入 CLAUDE §七。
- **Profile 输入框显示「北京」假象**：服务端已存「北京, 上海, 深圳」（浏览器 fetch 验证）。根因两连：① 首个 fixture 文件 `profile_put.json` 一次性写入故障只落了「北京」（node 字节级确认 len=2），② 改值后 `page.goto` 同 URL 不触发导航、组件不重挂载、快照不刷新——**硬刷新即完整显示，产品无 bug**。
- **Write 工具一次性丢内容**（上述 ①）：批量 fixture 写入后宜用 node 回读校验。
