# 本轮：插件鉴权 Token UX + 服务端会话同步（解除 README 长挂缺口）

## 核查→缺口（用户批准规划后执行）
- 缺口属实：插件零 token 代码（grep 无命中）→ fill-logs 打网关恒 401 静默失败（此前默认 baseUrl=8090 打 intelligence 更是 404，因 fill-logs 只在网关）；`/ext/v1/sessions` 服务端同步不可达。
- 设施现成：JwtAuthGuard 双凭证（`X-Ext-Token`）；`POST /api/v1/auth/login`（access 2h+refresh 30d，auth 限流 10/min）；sessions 契约齐（create/patch/block+状态机）；match-fields/dictionary/health 走 proxy 无守卫。
- 钩子现成：SW 已收 MATCH_FIELDS/STEP_CHANGED/REPORT_LOGS/SESSION_BLOCK → 内容脚本零改动。

## 交付
- `core/token-store.js`：toLoginBody/toRefreshBody/createAuth/fromTokenBundle（expires_in→绝对时刻）/isFresh（30s 提前量，粘贴无过期视为可用）/canRefresh/pickExtHeader；密码绝不落盘。
- `core/session-sync.js`：statsFromLogs/mergeStats/sessionCreatePayload/sessionPatchPayload/shouldSync（载荷映射纯函数）。
- `api-client.js`：requestJson 支持 headers+status；新增 login/refreshAuth/createSession/patchSession/blockSession；**reportLogs 改走 gatewayBase（默认 8080），修 404**；带 token 时加 X-Ext-Token。
