# 官网动效完整调整方案（待确认，暂不开发）

**版本**：v1.0 ｜ 2026-10-11
**对象**：`apps/site` 零构建静态站（当前：暗黑 landing，无动效）
**硬约束**：① 不引入构建链（无 npm run、无框架）；② `site.js` 保持小体积（目标 < 150 行非空）；③ 全部动效必须通过 `prefers-reduced-motion` 熄火；④ 冒烟 8 项保持全绿（新增动效断言只加不改口径）。

---

## 1. 目标与原则

| 目标 | 说明 |
|---|---|
| 活起来 | 首屏 3 秒内有层次地进场，滚动有反馈，悬停有响应——达到参考站"氛围感"的及格线（3D 除外） |
| 不拖慢 | 纯 CSS keyframes＋IntersectionObserver 触发，零图片/字体/库新增；动画只动 `transform`/`opacity`（不触发重排） |
| 可关闭 | 系统"减少动态效果"用户看到完全静态页；另在页脚加手动开关（`data-motion="off"` 存 localStorage，默认开） |
| 可验证 | 每个动效都有 smoke 断言（CSS 存在性）＋截图抽查（首屏/滚动位），有据可查 |

**不动**：布局结构、文案、色板、断点；Spline 级 3D（与零构建冲突，见 §6 备选）。

## 3. 技术实现要点

- **触发器**（site.js 新增约 45 行）：单个 IO 实例观察全部 `.rv` 元素，进视口加 `.in` 后 `unobserve`（一次性）；`matchMedia('(prefers-reduced-motion: reduce)')` 为真则跳过观察、直接全显；开关逻辑读写 `localStorage('qz.motion')`。
- **CSS 组织**：`site.css` 末尾新段落 `/* 动效 */`，约 90 行：`@media (prefers-reduced-motion: reduce)` 内 `*,*::before,*::after{animation:none!important;transition:none!important}` 熄火；`html[data-motion=off]` 同规则。
- **首屏防闪**：进场元素初始态 `opacity:0` 写在 CSS，但**无 JS 也能看**——用 `@media (scripting: none)` 回退全显？更简单：初始态由 `html.js .rv{opacity:0}` 限定（site.js 首行加 `document.documentElement.classList.add('js')`），无 JS 时全显。SEO/收录不受影响（爬虫读的是 HTML 文本）。
- **性能预算**：新增 CSS < 4KB，JS 增量 < 2KB；动画属性仅限 transform/opacity；`will-change` 只加在光晕层且滚动后移除（避免常驻显存）。

## 6. 备选与不做

| 项 | 结论 |
|---|---|
| Spline 真 3D | 不做：单个场景数 MB＋运行时，与零构建/性能预算冲突；光晕漂移是эмбл deliver 的氛围替代 |
| 滚动视差（parallax） | 不做：移动端抖动＋可访问性差，收益低于 C1–C4 |
| 页面转场 | 不做：单页无路由，转场无意义 |
| 数字滚动（使用人数） | 不做：无真实数据，不编数字（延续返工决议） |
| Lottie/Canvas 粒子 | 不做：体积与功耗超预算 |
