# 02 · 数据库设计

**数据库**：PostgreSQL 16
**字符集**：UTF8 ｜ **时区**：统一存 UTC（`timestamptz`）
**DDL**：见 `db/schema.sql`（可直接执行）

---

## 1. 设计约定

| 约定 | 说明 |
|---|---|
| 主键 | `id BIGSERIAL PRIMARY KEY` |
| 时间 | `created_at / updated_at timestamptz default now()` |
| 软删除 | 关键业务表带 `deleted_at timestamptz null` |
| 枚举 | 用 `varchar` + `CHECK` 约束（便于演进），不用原生 ENUM |
| 扩展字段 | 结构多变处用 `JSONB`，并建 GIN 索引 |
| 命名 | 表名小写下划线复数；外键 `xxx_id` |
| 索引 | 外键、唯一键、高频查询字段建索引；JSONB 建 GIN |

## 4. 索引与性能

| 场景 | 索引 |
|---|---|
| 资料查询 | `user_profiles(user_id)`；JSONB GIN |
| 岗位搜索 | `jobs(city)` `jobs(company)` `jobs(published_at desc)`；`jobs` 全文 GIN（标题+要求） |
| 去重 | `articles(url)` 唯一；`dedup_index(fingerprint)` 唯一 |
| 任务调度 | `crawl_tasks(source_id, status)`；`crawl_tasks(idem_key)` 唯一 |
| 会话日志 | `fill_logs(session_id)`；`fill_sessions(user_id, application_id)` |

**分区建议**：`articles` / `jobs` / `crawl_logs` / `llm_call_logs` 按 `created_at` 月分区（数据量增长后启用）。

---

## 5. 数据安全与合规

| 项 | 措施 |
|---|---|
| 敏感字段 | `user_profiles.basic_info` 中的护照号等，字段级 AES-256-GCM 加密后再入 JSONB |
| 材料文件 | 存对象存储，私有桶 + 预签名 URL，不落本地盘 |
| 密码 | `bcrypt`（cost≥12） |
| 采集合规 | `articles` 只存摘要 + 原文链接，不存全文；提供 `deleted_at` 下架软删 |
| 审计 | 登录、资料导出、批量填充、数据下架均写 `audit_logs` |
| 保留期 | `llm_call_logs` / `crawl_logs` 保留 90 天，到期归档 |

---

## 6. 迁移策略

- 目录：`db/migrations/`，命名 `YYYYMMDDHHMM__描述.sql`。
- 工具：初期手写 SQL + `schema_migrations` 表记录；规模上来后切 Alembic / Prisma Migrate。
- 规则：DDL 变更一律新增迁移文件，禁止直接改 `schema.sql` 后手工执行到线上。
