第一章

插件安装与使用

  • ① 安装 —— Chrome 商店搜索「留学网申助手」一键添加；或从 GitHub 下载 zip，在 chrome://extensions 开启「开发者模式」后加载已解压目录（零构建，无需任何打包工具）。
  • ② 同步资料 —— 先在控制台完善教育 / 标化 / 经历资料，插件自动同步 54 槽位词典。
  • ③ 打开网申页 —— 插件自动识别表单，弹出填充向导，逐字段展示预填值，敏感字段标红提醒。
  • ④ 人工复核 —— 每个字段可修改 / 跳过，确认后点「确认并继续」；插件绝不代替你点「下一步」或「提交」。
  • ⑤ 断点续填 —— 多步向导自动记录步骤，中断后可恢复；本地缓存 7 天有效。

    • 合规红线：不破解验证码、不自动提交——所有提交动作由本人复核后亲手完成。—— 留学生助手开发团队

    第二章

    字段匹配原理

    插件把页面表单字段映射到 54 个语义槽位，识别率 94.2%（精确 98.0%）。匹配分三级，逐级放宽：

    第一级 · 精确匹配

    字段 label 与词典词条完全一致（如 "First Name" → 姓名），零误判，优先命中。
    零成本→

    第二级 · 别名匹配

    同义词与常见变体（"E-mail" / "Email address" → 邮箱），覆盖平台差异写法。
    词典驱动→

    第三级 · 模糊匹配

    低置信度走相似度兜底，仍不确定则标出留给你手填，不猜、不错填。
    宁缺勿错→

    标签匹配采用行首锚定 + 紧跟分隔符规则，避免「岗位职责：xxx」被误判成字段名；GPA 换算与后端阶梯同一事实源，见 GPA 换算器。

    第三章

    采集与订阅推送

  • ① 建订阅规则 —— 在控制台输入关键词（AI、SDE）、城市（北京、上海）、岗位类型（实习 / 全职）、频率（每日）；
  • ② 多源采集 —— 采集服务按控制频次抓取公众号 / 招聘平台 / 企业官网公开信息，署名来源、不整篇转载；
  • ③ 去重入库 —— SimHash + 指纹去重，同岗位多来源只保留一条，坏数据逐条隔离不污染整批；
  • ④ 定时推送 —— 调度器扫描到期订阅，按渠道推送新匹配岗位，附原文链接；去重落在数据库唯一约束。

    • 权利人发现内容可随时联系下架，我们提供通道并优先处理；过期岗位自动下架，DDL 倒计时自动提醒。

    第四章

    控制台功能总览

    首页 / 岗位

    新手引导、上游服务健康检查；岗位列表支持分面筛选、排序、列显隐、CSV 导出与一键建订阅。

    订阅 / 申请进度

    订阅规则可视化配置（含自动执行与调度预设）、推送记录；申请进度看板支持行内编辑状态与 DDL 倒计时。

    成绩换算 / 资料库

    百分制 / 5 分制 / 英制 → 4.0 本地换算；资料库管理推荐信、文书与证明材料，敏感字段本地优先。

    需要鉴权的请求自动带 token、401 自动刷新；危险操作二次确认，列表页防抖 + 竞态保护。
